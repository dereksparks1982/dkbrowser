# ДК Браузер

**[Английская версия](README.md)** | **Русская версия**

**Бесплатный браузер с открытым исходным кодом от «ДК Софтворкс» на основе «Хромиума».**

</div>

## О проекте

**ДК Браузер** создаётся как самостоятельная версия браузера «Хромиум» с русским и английским интерфейсами. В этом репозитории находится полноценный исходный код браузера, а не программа-оболочка или ссылка на стороннюю разработку.

Наша цель — удобный браузер для повседневных задач, безопасного просмотра сайтов, воспроизведения видео, перевода страниц и работы с искусственным интеллектом. Подробнее о технических этапах можно узнать из [плана разработки](DK_BROWSER.md).

## Выбор языка

На панели инструментов предусмотрена заметная кнопка переключения между русским и английским языками. Выбранный язык сохраняется в настройках. После перезапуска браузер загружает соответствующие переводы.

В русской версии используется утверждённый значок с надписью **ДК БРАУЗЕР**, а в английской — отдельный значок с латинскими буквами. Русский интерфейс использует языковые ресурсы «Хромиума», а названия нашей программы в соответствующих переводах изменены на «ДК Браузер».

**Важно:** кнопка переключения и переводы добавлены в исходный код, но ещё не проверены в собранном приложении. Перед выпуском потребуется полноценная проверка русскоязычного интерфейса.

## Просмотр видео и аудио

При запуске новой сессии браузер по умолчанию открывает [ДК Медиаплеер](https://dereksparks1982.github.io/DK-Media-Player/). Настройки стартовой страницы, выбранные пользователем, и восстановление предыдущей сессии сохраняют приоритет.

Веб-плеер позволяет выбирать местные аудио- и видеофайлы, открывать прямые ссылки и сохранять позицию просмотра в поддерживаемых браузерах.

Поддержка видеокодека высокой эффективности с индексом 265, контейнера «Матроска» и защищённого потокового видео находится в разработке. Имеющиеся настройки сборки пока не гарантируют воспроизведение этих форматов.

## Искусственный интеллект

В [план разработки](DK_BROWSER.md) включено исследование русскоязычного помощника на основе открытых моделей семейства «Гигачат». Рассматриваются работа непосредственно на компьютере без обязательной учётной записи и возможность подключения собственного сервера.

**Модели пока не встроены в браузер. Равенство возможностей с «Алисой» от «Яндекса» не заявляется.**

## Местный помощник с искусственным интеллектом

В исходный код добавлен экспериментальный помощник с русским и английским интерфейсами. Он работает через отдельную страницу на вашем компьютере и использует только установленную пользователем местную модель. Можно выбрать один из двух местных способов подключения к модели. Ни один из них не требует подключения к внешнему серверу. Обязательной учётной записи и автоматической загрузки моделей нет.

Значок помощника автоматически меняется вместе с языком интерфейса: русская версия использует утверждённый значок с кириллицей, английская — с латиницей. Язык интерфейса запоминается без сохранения переписки. Пользователь может очистить сообщения или самостоятельно сохранить их в текстовый файл.

В исходном коде панели инструментов появилась отдельная кнопка **ДК ИИ**. По нажатию открывается новая вкладка с помощником, если местная служба уже запущена. Кнопка не считывает текущую страницу, не отправляет данные в сеть и не запускает дополнительные процессы.

Это пока самостоятельный опытный компонент, а не встроенная боковая панель браузера. Для его запуска требуется предварительно установить и запустить совместимую службу обработки запросов. Инструкция находится в [разделе о помощнике](dk_browser/ai/README.md).

## Сборка для Линукс

Разработка ведётся на основе исходного кода «Хромиума». Для самостоятельной сборки необходимы инструменты `depot_tools`, `gclient`, `gn`, `autoninja` и зависимости, описанные в файле `DEPS`.

Начальные параметры сборки: [файл настроек](dk_browser/args.linux.gn).

Подготовка значков для установки выполняется командой:

```bash
python3 dk_browser/tools/prepare_icons.py
```

Для работы этой команды требуется библиотека обработки изображений «Пиллоу».

**Готовый исполняемый файл браузера пока не выпущен.** Изменения сохраняются в репозитории исходного кода. Для проверки необходима отдельная сборка и испытания на Линуксе. Автоматическая сборка на платформе размещения исходного кода не используется.

## Раздельное хранение данных

ДК Браузер использует собственную папку для настроек, истории, закладок и расширений. Она отделена от папки исходного браузера «Хромиум», поэтому данные двух программ не смешиваются. При необходимости пользователь может выбрать другое расположение профиля стандартными параметрами запуска.

## Установка и обновления

В исходном коде подготовки пакетов для Линукса используется собственное название ДК Браузера, отдельная папка установки и русское название в меню приложений. Установочный пакет не должен добавлять сторонние источники обновлений или устанавливать чужие ключи подписи. Собственная служба обновлений ещё не создана.

Готовые установочные пакеты пока не собирались и не проверялись.

## Проверка исходного кода

Для проверки значков, русскоязычной документации, настроек браузера и основных ограничений безопасности предусмотрен местный инструмент. Он не загружает файлы из сети и не устанавливает программы. Команда запуска:

```bash
python3 dk_browser/tools/preflight.py
```

Инструмент не заменяет сборку браузера и проверку его работы.

## Лицензии и авторство

ДК Браузер сохраняет лицензии, юридические уведомления и сведения об авторах исходного проекта «Хромиум». Собственные изменения разрабатывает «ДК Софтворкс».

Перед распространением дополнительных компонентов защищённого воспроизведения, кодеков и моделей искусственного интеллекта необходимо проверить условия их лицензий.
