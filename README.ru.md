# ДК Браузер

**[English](README.md)** | **Русский**

**Бесплатный браузер с открытым исходным кодом от DK Softworks на основе Chromium.**

</div>

## О проекте

**ДК Браузер** разрабатывается как отдельная версия Chromium с русским и английским интерфейсами. Репозиторий содержит исходный код браузера, а не оболочку и не ссылку на стороннюю программу.

Мы хотим создать полноценный браузер для повседневных задач, безопасной работы, просмотра видео, перевода страниц и использования искусственного интеллекта. Подробности и этапы приведены в [плане разработки](DK_BROWSER.md).

## Выбор языка

В исходный код добавлена заметная кнопка **EN / РУ** на панели инструментов. Выбор языка сохраняется в настройках браузера, после чего браузер перезапускается и загружает соответствующие переводы. В русской версии используется утверждённый значок **ДК БРАУЗЕР**, в английской версии надписи выполнены латиницей.

Русские переводы интерфейса основаны на языковых ресурсах Chromium. Часть строк с названием программы уже переработана. Для полноценного выпуска требуется проверка переводов носителями русского языка.

## Просмотр видео и аудио

Стартовая страница новой сессии по умолчанию открывает [ДК Медиаплеер](https://dereksparks1982.github.io/DK-Media-Player/). Пользовательские настройки стартовой страницы и восстановление сессии сохраняют приоритет. Веб-плеер открывает локальные аудио- и видеофайлы, поддерживает прямые ссылки и сохраняет позицию воспроизведения.

Поддержка H.265, MKV и защищённого видео пока разрабатывается. Текущие настройки сборки сами по себе не гарантируют декодирование или совместимость с потоковыми сервисами.

## Искусственный интеллект

В [плане разработки](DK_BROWSER.md) рассматривается русскоязычный помощник на основе открытых моделей семейства GigaChat. Предусмотрены локальная работа без обязательной учётной записи и возможность подключения собственного сервера. **Модели пока не встроены, и равенство возможностей с Алисой не заявляется.**

## Сборка для Linux

Разработка ведётся на основе исходного кода Chromium. Для сборки потребуются инструменты `depot_tools`, `gclient`, `gn`, `autoninja` и зависимости из `DEPS`. Параметры проекта находятся в [dk_browser/args.linux.gn](dk_browser/args.linux.gn). Подготовка значков: `python3 dk_browser/tools/prepare_icons.py` (требуется Pillow).

**Готового исполняемого файла пока нет.** Изменения вносятся непосредственно в репозиторий GitHub; для проверки потребуется отдельная сборка на Linux. Автоматическая сборка через GitHub Actions не используется.

## Лицензии

ДК Браузер сохраняет лицензии и авторство Chromium. Изменения DK Softworks разрабатываются отдельно. Перед распространением компонентов защищённого воспроизведения, кодеков и моделей необходимо проверить их лицензионные условия.
